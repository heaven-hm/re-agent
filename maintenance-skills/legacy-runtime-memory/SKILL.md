# Legacy Runtime Memory

Use existing RE-Agent process, Frida, debugger, native-UI and browser operations only when advertised and applicable. Prefer owned launches; attach only to an explicitly authorized process, binding executable hash and start identity. Record actual working directory, assets, input script, modules, ASLR, architecture, ticks and outcomes. Never silently restart a pre-existing game or broaden OS permissions. For captured memory, memory-snapshot-pattern returns file offsets only. Verify pointer width, layout, liveness and sampling phase before interpreting values. Missing access or dropped trace data stays UNVERIFIED. No cheat, freeze, trainer or original-memory-write workflow is part of this skill.
