# Legacy Triage

Record the user-authorized target, executable SHA-256, version, platform, support-status references and expected behavior. Public availability or end of support is not authorization. Use maintenance-plan to bind these inputs; unknown rights or target identity remain blockers for repair. Keep the original read-only, choose a sandbox/worker for execution, and reproduce one issue before changing code. Create an evidence-backed backlog: reproduction, affected scope, severity, evidence IDs, status and regression case. Do not label heuristic findings as confirmed bugs.
