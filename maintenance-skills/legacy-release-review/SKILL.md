# Legacy Release Review

Inventory the actual tested host/target matrix and link builds, tests, traces, known failures and unresolved behavior. Review bundled component licenses, preserve upstream attribution and establish rights for every original asset/binary before redistribution. Project code stays MIT; the responsible-use policy describes supported scope and does not replace the license. Preserve previous reports and failed experiments. Publish/rename/release only within explicit user authorization and existing repository workflow. Do not publish credentials or private captures. State unsupported OS workers and proposed integrations as unverified, rather than silently claiming all platforms pass.
