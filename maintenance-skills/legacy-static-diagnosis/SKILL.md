# Legacy Static Diagnosis

Use the existing selected provider: Ghidra/radare2/native inspection or managed analysis as appropriate. Record actual function boundaries, callers, imports, strings, types and uncertainty. Investigate unsupported APIs, architecture assumptions, file formats, resource paths and crashes. Distinguish missing dependencies from defects. Recover hypotheses from binary evidence; never invent native functions or claim decompiled pseudocode is original source. Retain evidence IDs and exact addresses/build hashes for every proposed repair.
