# Legacy Cross Platform Port

Establish reference operating-system, ABI, dependency, timing, resource and file-format assumptions from authenticated binary and runtime evidence. Define a bounded, explicit behavioral contract before implementing new platform code. Keep proprietary originals and assets separate from the candidate and respect licensed distribution boundaries. Recreate declared external behavior using target-platform APIs, recording intentional platform-specific differences. Test matched inputs, errors, file outputs and state transitions in separate original and candidate environments; report observations unavailable on a platform as unverified. Byte equality of executables across OS/CPU targets is neither required nor a valid behavioral equivalence claim.
