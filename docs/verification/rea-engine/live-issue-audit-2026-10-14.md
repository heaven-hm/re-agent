## Tool gap summary

Existing high-value integrations include Ghidra, IDA, Hopper, Frida, LLDB tracing,
browser/CDP and Playwright, process supervision, native UI observation and Z3
availability. Distinct gaps include instruction/basic-block coverage (QBDI or
DynamoRIO), native binary symbolic execution (angr), and graphics capture. The
redistribution audit found RenderDoc’s upstream policy and macOS/Metal support
limits incompatible with the general proprietary-target claim; do not market it
as a general integration. Rizin/apitrace/QBDI/AFL++ need package-specific
dependency and license review. See the
[tool gap audit](redistribution-gap-audit-2026-10-14.md).

No issue is closed in this audit merely because work is deferred. Existing #9
and #18 cover redistributable tool packaging; #5 and #6 cover reconstruction
benchmarks, so no duplicate issues were created.
