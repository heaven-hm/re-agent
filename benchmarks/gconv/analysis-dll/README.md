## Format and command observations

- `GConv 3.5` string: `0x10046de8`.
- Targa type diagnostics at `0x10047f38` and subsequent image-type strings show TGA RGB, monochrome, color-map and RLE variants.
- Output mode strings: Dreamcast `0x100475e8`, PC_Software `0x100475f8`, PC_Glide `0x10047604`.
- Texture format strings include ARGB8888, RGB565, ARGB4444, ARGB1555, Palette4 and Palette8 (`0x10047628`–`0x10047678`).
- `MakeTGA`, `MakeTexture`, `MakeMultiTexture`, `MakePalette`, `MakePicture`, font and animation commands are observed strings; implementations and accepted arguments still need dossiers/runtime experiments.
- `VqCalc` is the native exported vector-quantization entry. Version-resource string identifies `VQGEN Image Compression Tool Dll`; iteration/error strings support the compression interpretation.

## Reproduction

Run `node benchmarks/gconv/analysis-dll/recover-dll.mjs <authorized DLL path>` with `GHIDRA_INSTALL_DIR` and `JAVA_HOME` configured. This uses REA MCP `open_binary`, `list_procedures`, `list_strings`, `analyze_function`, and `close_binary`; it does not read upstream source code.

The `*-signature-failed.json` records are failed macOS codesign-provider attempts caused by sandboxed compiler-cache writes; they do not establish PE signature validity. Static Ghidra runs required permission for the process ownership Swift helper cache.

## Suggested bounded port scope

Start with path/config API and command-line/script grammar, then one TGA-to-identified-texture mode. Capture original generated bytes for independently generated fixtures and compare all bytes. VQ output must remain unverified until algorithm state, numerical behavior, input layout and output codebook ordering are measured. A native macOS executable will have different executable bytes from the Windows PE; equality claims must identify the artifact being compared.

## Dossier observations

Each `*-function-0x*.json` contains REA evidence, pseudocode, assembly, CFG blocks, calls/references and inferred type limitations. The native export selection produced 29 gconvapi dossiers and one VqCalc dossier.

- `gcInit` (`0x10007060`) and `gcSetAutoVQ` (`0x1000ca70`) are single RET instructions in this binary.
- `gcSetInputPath` (`0x10003ec0`) copies at most 511 bytes to `0x1004e688` then writes a NUL terminator at `0x1004e887`; a null input leaves the buffer unchanged. Getters invoke path normalization before returning the buffer, so a direct getter clone still requires its callee.
- `gcSetTextureFormat` (`0x1000c9f0`) accepts integer values 1 through 5; invalid values preserve the global and call `gcMessage` at level 2. `gcSetOutputMode` (`0x1000ca20`) accepts 0 through 2.
- Transparency, mipmap, dithering, transparent color, error level, and verbosity setters write raw 32-bit arguments to globals; observed setter bodies perform no boolean normalization.
- `gcExecuteScript` (`0x10007110`) delegates loading to `FUN_1001d4d0`, initialization to `FUN_10016eb0`, and execution to `FUN_10017410`/`FUN_10017210`. Those script-engine internals remain unrecovered.
- `VqCalc` (`0x100035f0`) has decompiler stack-recovery artifacts: parameters appear at large `in_stack_0000d9*` offsets. This is insufficient to assert its ABI, and its quantizer/packing callees remain unverified.

No original DLL was copied into this repository. No independent implementation or runtime parity has been claimed by this static-recovery step.
