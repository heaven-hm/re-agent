# Supported use of RE-Agent

RE-Agent — Reverse Engineering Agent — supports authorized preservation, maintenance, compatibility repair and independent porting of discontinued or unsupported software and games. Controlled fixtures may be used to develop and verify the platform itself.

Record the target, support-status evidence, authorization and intended change. End of support does not place software in the public domain or grant rights to its binaries, source, artwork, audio or other assets. Preserve original files and work in an isolated replica workspace. Respect required notices and distribution rights.

The project does not support cheat/trainer generation, multiplayer tampering, DRM/license/access-control bypass, unauthorized process changes, damage, sabotage, credential theft or unauthorized access. A community skill does not confer permission to run code, modify an original program, contact services or publish artifacts.

An authorized coding agent may investigate and repair within the agreed scope and finite budgets. Keep checkpoints, failures and regressions; stop when evidence, authority or a required original environment is unavailable. Publishing or changing another system requires the user's applicable authorization.

This is a project support and contribution policy. The MIT license remains the software license; this document does not add field-of-use restrictions to it. Third-party tools and original targets retain their own rights and terms. RE-Agent cannot guarantee that arbitrary binaries can be reconstructed or that generated code is correct.
